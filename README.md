# StoreWell 3D — Gate Storage PWA
- **Platform**: Cloudflare Pages
- **URL**: storewell-3d.pages.dev
- **Backend**: Firebase Realtime Database
- **Type**: 3D gate storage management app

## Deploy
npx wrangler pages deploy ./dist --project-name=storewell-3d

## Notes
- Firebase backend (storewell-3d-default-rtdb.firebaseio.com)
- Gate lock control integrated with Ohana Brain
